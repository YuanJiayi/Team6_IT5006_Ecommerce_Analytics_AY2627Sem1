# Phase 2 modelling notebooks

Add the classification and regression notebooks here as the team defines the Phase 2 problems. Build modelling tables from the raw Olist CSVs in `data/`, with one row per order and features available at the prediction point. Reusable preprocessing code can be added after the modelling design is agreed.

Use the primary chronological split and expanding validation indices in [`milestone2/data_prep.ipynb`](../../milestone2/data_prep.ipynb) for model selection and future-order claims. The random split is a separate secondary benchmark. See the [evaluation protocol](../../milestone2/evaluation_protocol.md) before fitting models.
