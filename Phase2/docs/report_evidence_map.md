## Interpretation and remaining limits

The five chronological validation windows establish the model comparisons. The test period was available during later development; its drift, refresh and subgroup checks are descriptive and do not provide a fresh independent holdout. The 10% review share is an illustrative capacity setting. The replay counts identify candidates for review, not proven effects of carrier intervention. Checkout availability of the stored promise, payment details and static ZIP coordinates is assumed because the source data contain no historical snapshots for them.

The notebooks display saved results and explain each stage. The training and evidence scripts are the executable record for model fitting, feature timing, metric calculation and report table generation. Bibliographic sources for the literature precedents are listed in the report bibliography; the Olist-specific feature choices and all result calculations are evidenced by the code and saved outputs above.
